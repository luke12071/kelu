# kelu设备监控仪表盘 devdash 1.0.6 安装包

## 目录结构
```
devdash-1.0.6/
├── 安装说明.md
├── devdash-维护记录.md             # 全部功能/安装/卸载/依赖说明
├── devdash-使用说明.md             # ImmortalWrt 安装说明
├── luci-app-devdash_1.0.6-1_all.ipk      # 功能包（iStoreOS/OpenWrt opkg）
├── app-meta-devdash_1.0.6-1_all.ipk      # iStore 元信息包（推荐，依赖功能包）
└── immortalwrt/
    ├── devdash-immortalwrt-1.0.6.run     # 一键安装器（推荐，离线可用）
    ├── luci-app-devdash_1.0.6-r1_all.apk # APK v3（ImmortalWrt 25.12+）
    └── devdash-diagnose.sh               # 诊断脚本
```

## 选择与安装

### iStoreOS / OpenWrt（opkg）
```sh
# 推荐：iStore 元信息包
is-opkg install /path/app-meta-devdash_1.0.6-1_all.ipk
# 或直接 opkg
opkg update && opkg install /path/luci-app-devdash_1.0.6-1_all.ipk
```

### ImmortalWrt 25.12+（apk，不支持 opkg）
```sh
# 推荐：.run 一键（无需软件仓库，离线可装）
sh /path/devdash-immortalwrt-1.0.6.run
# 或手动 apk（需仓库可用）
apk add --force-non-repository --allow-untrusted ./immortalwrt/luci-app-devdash_1.0.6-r1_all.apk
```

## 卸载
```sh
is-opkg remove luci-app-devdash     # iStoreOS/OpenWrt
apk del luci-app-devdash            # ImmortalWrt
# .run 安装方式：见 devdash-使用说明.md（手动删除 8 个文件 + cron 两行）
```

## 依赖
**无硬依赖**（独立 CGI，不依赖 luci-base）。可选：`tcpdump`（抓包）、`openssl-util`（密码哈希，缺失自动回退）。

## 访问
`http://<设备IP>/cgi-bin/devdash`，默认账号 admin，密码见安装提示（iStoreOS 本机为 devdash）。
